Политика конфиденциальности

Приложение «Свои: объявления Луганска» — дата вступления в силу: 18.07.2026

Кто обрабатывает данные

Оператором обработки персональных данных пользователей приложения «Свои» является его разработчик. Контакт для обращений: sergei.shvachyov@yandex.com.

Какие данные собираются

  • адрес электронной почты и пароль — для входа в аккаунт;
  • имя, номер телефона и район — указываются пользователем в профиле, по желанию;
  • текст и фотографии объявлений, которые пользователь размещает самостоятельно;
  • сообщения в чате с другими пользователями приложения;
  • технические данные устройства — для устранения сбоев в работе приложения.

Приложение не запрашивает точное GPS-местоположение — район указывается пользователем вручную из списка.

Для чего используются данные

Регистрация и вход в аккаунт, публикация и показ объявлений, работа чата между пользователями, модерация объявлений, техническая поддержка. Данные не используются в рекламных целях и не передаются третьим лицам для маркетинга.

Правовое основание

Обработка ведётся на основании согласия пользователя, предоставляемого при регистрации, в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Где хранятся данные

Данные хранятся на инфраструктуре стороннего сервиса Supabase, выступающего обработчиком по поручению Оператора. Пароль хранится в зашифрованном виде.

Права пользователя

  • получить информацию об обработке своих персональных данных;
  • исправить неточные данные — через раздел «Редактировать профиль» в приложении;
  • удалить объявления самостоятельно, в любой момент;
  • отозвать согласие и потребовать удаления аккаунта — обратившись на sergei.shvachyov@yandex.com.

Несовершеннолетние

Приложение не предназначено для лиц младше 18 лет.
